Components

Tooltip

A small dark label on an ink-filled box — flat, sharp, no radius. Wrap a trigger in .ds-tooltip-host and it reveals a child .ds-tooltip on hover or keyboard focus, no JavaScript required.

CSS-only

Hover or tab to the trigger to reveal the tooltip. The .ds-tooltip-host wrapper shows its child .ds-tooltip on :hover / :focus-within, positioned above by default.

Hover / focus host
Recalculates the full pricing matrix 
<span class="ds-tooltip-host">
  <button class="ds-button">Hover me</button>
  <span class="ds-tooltip">Recalculates the full pricing matrix</span>
</span>

Placement

Add --top (default), --bottom, --left, or --right to the .ds-tooltip to move it around the trigger.

top · bottom · left · right
Above the trigger Below the trigger To the left To the right 
<span class="ds-tooltip-host">
  <button class="ds-button">Bottom</button>
  <span class="ds-tooltip ds-tooltip--bottom">Below the trigger</span>
</span>

Bare box

The .ds-tooltip on its own is just a small dark box — useful inside a JS-positioned layer.

.ds-tooltip
Tabular rate · €/day 
<span class="ds-tooltip">Tabular rate · €/day</span>

React

Changed in 1.0. Tooltip is now a composition — trigger and content are separate parts — and it renders .ds-tooltip-content, not the .ds-tooltip-host markup above. It dismisses on Esc and the popup stays open while the pointer is over it, both of which WCAG 1.4.13 requires and neither of which 0.11 did.

Name the trigger yourself. A tooltip is a visual supplement: it wires no aria-describedby, so a screen reader gets only the trigger’s own accessible name. Give an icon-only trigger an aria-label that says the same thing the tooltip says. If the text is essential rather than supplementary, it does not belong in a tooltip at all — put it inline, or in a Popover.

<Tooltip> 
import {
  Tooltip, TooltipTrigger, TooltipContent, TooltipProvider, Button,
} from "@diametral/design-system/react";

// One Provider per screen shares the open/close delay across every tooltip.
<TooltipProvider delay={200}>
  <Tooltip>
    <TooltipTrigger render={<Button aria-label="Recalculate pricing" />}>
      Recalculate
    </TooltipTrigger>
    <TooltipContent side="top">Recalculate pricing</TooltipContent>
  </Tooltip>
</TooltipProvider>

// 0.11: <Tooltip label="…" placement="top"><Button/></Tooltip>
// `placement` is `side` on TooltipContent, and `label` is its child.
