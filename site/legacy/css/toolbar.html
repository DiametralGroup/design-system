Components

Toolbar

A boxed strip that aligns controls on one row — buttons, a segmented control, a search field. It is width: fit-content, so it sizes to its contents; cluster related controls with .ds-toolbar-group and rule between them with .ds-toolbar-separator. Widen the bar yourself and .ds-toolbar-spacer will push the clusters to opposite edges.

Groups and spacer

A left group of actions, a .ds-toolbar-spacer, and a right group. The spacer only does anything on a bar widened past its content, which is why this one carries an inline width.

Search · segmented

The bar is boxed in a 1px rule by default — 0.11 needed --bordered for that. It mixes a search .ds-input, a .ds-segmented control and buttons on the same row.

.ds-toolbar 
<div class="ds-toolbar" role="toolbar" style="width:100%">
  <input class="ds-input" type="search" placeholder="Search rows…" aria-label="Search">
  <div class="ds-segmented">
    <button class="ds-segmented__item is-active" aria-pressed="true">All</button>
    <button class="ds-segmented__item" aria-pressed="false">Active</button>
    <button class="ds-segmented__item" aria-pressed="false">Archived</button>
  </div>
  <div class="ds-toolbar-spacer" aria-hidden="true"></div>
  <button class="ds-button">Filters</button>
</div>

React

Base UI's Toolbar underneath, so the whole strip is one tab stop and the arrow keys walk it — where 0.11's flex row made every control its own stop. There is no spacer: the bar is sized to its content, so there is no free space to eat.

<Toolbar /> 
import {
  Toolbar,
  ToolbarGroup,
  ToolbarInput,
  ToolbarSeparator,
  ToolbarButton,
} from "@diametral/design-system/react";

<Toolbar>
  <ToolbarInput type="search" placeholder="Search rows…" aria-label="Search" />
  <ToolbarSeparator />
  <ToolbarGroup>
    <ToolbarButton aria-label="Export"><DownloadIcon /></ToolbarButton>
    <ToolbarButton aria-label="Delete" variant="danger"><TrashIcon /></ToolbarButton>
  </ToolbarGroup>
</Toolbar>
