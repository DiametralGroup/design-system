Components

Drawer

An off-canvas panel anchored to an edge of the viewport over a dimmed scrim: a bordered head with a title and close button, a scrollable body, and an optional footer. Slides in via a transform, anchored right by default — or left, top, bottom.

Static panel

The drawer panel on its own (the fixed .ds-drawer-overlay scrim is omitted here so it renders in flow). Head, scrollable body, and a footer pushing the primary action right with a .ds-drawer__spacer.

Placement

Modifiers dock the panel to an edge: .ds-drawer--right (default) and .ds-drawer--left for side panels, .ds-drawer--top / .ds-drawer--bottom for sheets.

Interactive

A trigger opens the live fixed overlay; it closes on the close button, a backdrop click, or Escape. The panel slides in from the right (held still under prefers-reduced-motion).

<div class="ds-drawer-overlay" id="demoDrawer">

    <div class="ds-drawer__head">

<script>
  const ov = document.querySelector("#demoDrawer");
  document.querySelector("#drawerOpen").onclick = () => ov.classList.add("is-open");
  const close = () => ov.classList.remove("is-open");
  ov.addEventListener("click", (e) => { if (e.target === ov) close(); });
  ov.querySelectorAll("[data-drawer-close]").forEach((b) => b.onclick = close);
  document.addEventListener("keydown", (e) => { if (e.key === "Escape") close(); });
</script>

React

Changed in 1.0, and this one needs reading. 0.11’s one Drawer did two jobs, and 1.0 splits it in two. Sheet is the edge-docked panel that placement meant — that is where a 0.11 call site goes. Drawer keeps its name but is now the swipeable sheet: snap points, a swipe axis, an optional grab handle, uncontrolled by default.

Because the name survives, a 0.11 <Drawer open placement="right"> will not necessarily fail to compile — it will just render the wrong thing. This is the one 1.0 change worth grepping for by hand.

Both are Base UI dialogs, so both add what 0.11 never had: a real focus trap (Tab cycles inside the panel instead of walking out into the page behind it) and a portal. The classes above are 0.11’s and still work for hand-written HTML; the React components render .ds-sheet-* / .ds-drawer-popup instead.

<Drawer> 
import {
  Sheet, SheetTrigger, SheetContent, SheetHeader, SheetTitle,
  SheetDescription, SheetFooter, SheetClose, Button,
} from "@diametral/design-system/react";

// The 0.11 <Drawer placement="right"> lands HERE, on Sheet.
// No `open` needed: the trigger owns it. Pass `open`/`onOpenChange` to control.
<Sheet>
  <SheetTrigger render={<Button variant="primary" />}>Open drawer</SheetTrigger>
  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Filters</SheetTitle>
      <SheetDescription>Narrow the result set.</SheetDescription>
    </SheetHeader>
    <p>Body content…</p>
    <SheetFooter>
      <SheetClose render={<Button variant="primary" />}>Apply</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
