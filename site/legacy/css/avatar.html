Avatar

A flat, sharp square showing initials or a cover-fit image under a 1px hairline. Size is data-size (sm · default · lg); initials go in a .ds-avatar-fallback, which is the slot the React binding shows only once an image has actually failed. Groups overlap and end in a .ds-avatar-group-count.

React

Avatar · AvatarGroup 
import {
  Avatar,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage,
} from "@diametral/design-system/react";

<Avatar size="lg">
  <AvatarFallback>VD</AvatarFallback>
</Avatar>

{/* The fallback shows only once the image has failed or is still loading —
    that is Base UI's Avatar, and it is what the 0.x applier could not do. */}
<Avatar>
  <AvatarImage src="https://i.pravatar.cc/96?img=32" alt="Leo Marsh" />
  <AvatarFallback>LM</AvatarFallback>
</Avatar>

{/* The overflow count is written, not computed: 0.x's `max` prop is gone
    because a group is now parts, and the caller already knows the total. */}
<AvatarGroup>
  <Avatar>
    <AvatarImage src="https://i.pravatar.cc/96?img=12" alt="Maria Vance" />
    <AvatarFallback>MV</AvatarFallback>
  </Avatar>
  <Avatar><AvatarFallback>JL</AvatarFallback></Avatar>
  <AvatarGroupCount aria-label="3 more">+3</AvatarGroupCount>
</AvatarGroup>
