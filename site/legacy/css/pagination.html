Components

Pagination

A strip of page controls with prev/next and an ellipsis where the run is collapsed. Each page is a .ds-button — the active one takes --primary and fills with ink — inside a .ds-pagination-content list, so the pager is a real list of links or buttons rather than a bespoke button family.

Interactive

Click a page or the prev/next controls. The active page carries .ds-button--primary and aria-current="page"; the nav controls take disabled at the ends of the range.

Live 
<nav class="ds-pagination" role="navigation" aria-label="Pagination">
  <ul class="ds-pagination-content">
    <li><button class="ds-button ds-pagination-previous" aria-label="Go to previous page" disabled>
      <span class="ds-pagination-label">Previous</span></button></li>
    <li><button class="ds-button ds-button--icon ds-button--primary" aria-current="page">1</button></li>
    <li><button class="ds-button ds-button--icon">2</button></li>
    <li><button class="ds-button ds-pagination-next" aria-label="Go to next page">
      <span class="ds-pagination-label">Next</span></button></li>
  </ul>
</nav>

React

The React binding is parts, not a controlled component: paginationRange() computes the window and you render it. That is what lets a page be a real <a href> — crawlable and middle-clickable — instead of a button that only works with JavaScript.

<Pagination /> 
import { useState } from "react";
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
  paginationRange,
} from "@diametral/design-system/react";

const [page, setPage] = useState(6);

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious onClick={() => setPage(page - 1)} />
    </PaginationItem>
    {paginationRange({ page, pageCount: 24 }).map((slot, i) =>
      slot === "ellipsis" ? (
        <PaginationItem key={`gap-${i}`}><PaginationEllipsis /></PaginationItem>
      ) : (
        <PaginationItem key={slot}>
          <PaginationLink
            href={`?page=${slot}`}
            isActive={slot === page}
            onClick={() => setPage(slot)}
          >
            {slot}
          </PaginationLink>
        </PaginationItem>
      )
    )}
    <PaginationItem>
      <PaginationNext onClick={() => setPage(page + 1)} />
    </PaginationItem>
  </PaginationContent>
</Pagination>
