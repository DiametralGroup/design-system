Kanban

A board of columns holding draggable cards. The React <Kanban> moves them with the pointer or the keyboard — every card carries a grip button, so Space lifts, the arrow keys move, Space drops and Esc cancels — and fires onMove(itemKey, toColumnId) only when a card changes column. Drag or tab a card live in the demo app. The classes below are the static shell; without the React binding there is no drag at all.

React

<Kanban>
import { Kanban, KanbanCardTitle } from "@diametral/design-system/react";

// defaultItems lets the board own the order. Pass `items` + `onItemsChange`
// instead to control it — passing `items` alone pins every card in place.
<Kanban
  columns={[{ id: "todo", title: "To do" }, { id: "doing", title: "In progress" }, { id: "done", title: "Done" }]}
  defaultItems={[{ id: "t1", column: "todo", title: "Define thresholds" }, { id: "t2", column: "doing", title: "Calculator v2" }]}
  renderCard={(t) => <KanbanCardTitle>{t.title}</KanbanCardTitle>}
  onMove={(id, col) => save(id, col)}
/>
