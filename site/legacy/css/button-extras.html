Button group

Buttons joined into one control. The group removes the losing border between members rather than overlapping them, so the seam is correct under dir="rtl" too. Since 1.0.0-beta.3 it also takes a data-orientation, a .ds-button-group-text cell and a .ds-button-group-separator.

.ds-button-group
<div class="ds-button-group" role="group" data-orientation="horizontal">
  <button class="ds-button">Day</button>
  <button class="ds-button">Week</button>
  <button class="ds-button">Month</button>
</div>
.ds-button-group-text / -separator
EUR 
<div class="ds-button-group" role="group" data-orientation="horizontal">
  <span class="ds-button-group-text">EUR</span>
  <button class="ds-button">Copy</button>
  <!-- --auto sizes the rule to the group instead of the cross axis -->
  <span class="ds-button-group-separator ds-separator ds-separator--auto"
        role="separator" data-orientation="vertical" aria-orientation="vertical"></span>
  <button class="ds-button">Paste</button>
</div>
[data-orientation="vertical"]
<div class="ds-button-group" role="group" data-orientation="vertical">
  <button class="ds-button">Export as CSV</button>
  <button class="ds-button">Export as JSON</button>
  <button class="ds-button">Copy to clipboard</button>
</div>

React

JSX
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText, IconButton, SplitButton } from "@diametral/design-system/react";

<ButtonGroup><button className="ds-button">Day</button>…</ButtonGroup>
<ButtonGroup orientation="vertical">
  <ButtonGroupText>EUR</ButtonGroupText>
  <Button>Copy</Button>
  <ButtonGroupSeparator />
</ButtonGroup>

// `size` is one of the four square sizes: icon | icon-xs | icon-sm | icon-lg
// (the bare sm / lg from 0.x still work). `label` is required.
<IconButton label="Add" variant="primary" size="icon-sm"><PlusIcon /></IconButton>
<SplitButton variant="primary" onMain={save} menu={<div className="ds-menu">…</div>}>Save</SplitButton>

// the base Button also takes size / loading / block:
<Button size="lg" loading>Saving</Button>
