Components

Breadcrumb

A compact path trail rendered as an ordered list. Links are soft ink, a faint / separates the items, and the current page — marked aria-current="page" — sits in full ink.

Trail

Each step is a ds-breadcrumb-item; intermediate steps wrap a ds-breadcrumb-link and the last is a ds-breadcrumb-page. The separator is its own presentational <li> rather than a generated ::after — an element can be flipped for RTL, and it stays out of the accessible name of the item beside it.

React

Pass an ordered items array of { label, href }; the last item becomes the current page automatically.

<Breadcrumb /> 
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@diametral/design-system/react";

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem><BreadcrumbLink href="/">Home</BreadcrumbLink></BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      {/* render swaps in a router's own Link with no wrapper element */}
      <BreadcrumbLink render={<Link to="/pricing" />}>Pricing</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem><BreadcrumbPage>Matrix</BreadcrumbPage></BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
