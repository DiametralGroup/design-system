Components

Charts

Twelve of the sixteen charts are React-only: line, area, bar, stacked bar, pie and donut from 1.0.0-beta.4, then radar, combo, funnel, scatter, treemap and waterfall from 1.0.0-beta.5. All twelve draw their marks with recharts, so there is no markup that reproduces them and no class per mark. What the stylesheet owns is the frame — .ds-chart-container, .ds-chart-tooltip-content and .ds-chart-legend-content — plus the descendant rules that repaint recharts' hard-coded #ccc gridlines and #fff outlines onto --ds-* tokens. Each one is documented, with a live playground, in the React workbench.

Four stay library-free and are the ones a non-React binding can still render: the gauge and the bullet chart and heatmap below, plus the sparkline. 0.11's pure-SVG .ds-chart, .ds-linechart, .ds-areachart, .ds-donut, .ds-piechart, .ds-stackedbar and .ds-barchart classes were removed in beta.4; from-0.11.md maps every one.

Gauge

A .ds-gauge draws a faint 270° -track arc behind a coloured -value arc (length via stroke-dasharray, so the arc redraws without recomputing its path), with a big -center number and an optional uppercase -label. The arc colour defaults to --ds-chart-1; pass a colour or value→colour thresholds.

Bullet chart

The reading .ds-meter, .ds-gauge and .ds-progress cannot carry: an actual against a target and its qualitative bands. Three grid columns — label, track, figure — and the two outer ones are fixed widths read from --ds-bullet-label and --ds-bullet-value, because the primary use is a stack and intrinsic columns would leave every row starting at a different x. The role="meter" and the accessible name go on the track, and the target goes into aria-valuetext: it is geometry only, and invisible to a screen reader otherwise.

Heatmap

The only chart here that encodes magnitude as colour rather than position, which is what lets it scale to hundreds of cells. CSS grid and divs — the cell colour, size and the grid's track counts are inline because all three are derived from the data. The ramp is --ds-heat-1 to --ds-heat-5, sequential and one hue: the categorical --ds-chart-* ramp read as a scale is the classic dataviz error. Colour being the only encoding, every cell carries its own accessible name with both axes and its value; an empty cell is a ring rather than a paler tint, because no reading is a different thing from a low one.

The frame

These three classes are what a recharts chart lands in, and the only chart classes a consumer writes by hand. .ds-chart-container is a 16/9 box; --plot swaps that for a fixed height and full width (the axis charts), --square for a 1:1 box (pie, donut, radar), and both read --ds-chart-height — the knob that replaced the source's Tailwind height literals. Three charts default that knob on their own root instead, because each needs vertical range the axis charts do not: .ds-funnel-chart-root, .ds-treemap-root and .ds-scatter-chart-root, all at 16rem.

The twelve React charts 
// recharts is an optional peer dependency, like react:
//   npm i recharts
import {
  LineChart, AreaChart, BarChart, StackedBar, PieChart, DonutChart,
  RadarChart, ComboChart, FunnelChart, ScatterChart, Treemap, WaterfallChart,
} from "@diametral/design-system/react";

const config = {
  signups: { label: "Signups", color: "var(--ds-chart-2)" },
  churn: { label: "Churn" },   // takes the next --ds-chart-* slot
};

<LineChart config={config} data={rows} xAxisKey="week" />
<BarChart config={config} data={rows} xAxisKey="week" max={300} horizontal />
<DonutChart config={config} data={rows} valueKey="gb" nameKey="bucket"
            centerLabel="8.2 GB" centerCaption="of 10 GB" />

// beta.5. Same config + data contract; each names the row fields it reads.
<ComboChart config={config} data={rows} xAxisKey="month"
            series={[{ key: "revenue", type: "bar" },
                     { key: "margin", type: "line", axis: "right" }]}
            rightAxis={{ label: "Margin %" }} />
<FunnelChart data={rows} nameKey="stage" valueKey="users" />
<WaterfallChart data={rows} nameKey="step" valueKey="delta"
                totalKeys={["Opening", "Closing"]} />
<ScatterChart config={config} data={rows} xKey="weight" yKey="bounce"
              sizeKey="visits" xLabel="Page weight (KB)" />
<Treemap data={rows} />
<RadarChart config={config} data={rows} dimensionKey="capability"
            domain={[0, 100]} />
