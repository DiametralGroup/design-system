Components

Description list

A <dl> laid out as a two-column grid — an auto-width uppercase ds-description-term column and a 1fr ds-description-detail value column. Each pair is one row, divided from the next by a soft rule. Built for key/value detail readouts with tabular figures.

Key / value rows

Uppercase faint terms on the left, ink values on the right. Rows are separated by --ds-rule-soft.

React

The DescriptionList component takes an items array of { term, desc } pairs.

<DescriptionList /> 
import {
  DescriptionList,
  DescriptionTerm,
  DescriptionDetail,
} from "@diametral/design-system/react";

<DescriptionList>
  <DescriptionTerm>Day rate</DescriptionTerm>
  <DescriptionDetail>€900</DescriptionDetail>
  <DescriptionTerm>Salary</DescriptionTerm>
  <DescriptionDetail>€48,000</DescriptionDetail>
  <DescriptionTerm>Margin</DescriptionTerm>
  <DescriptionDetail>32.5%</DescriptionDetail>
</DescriptionList>
