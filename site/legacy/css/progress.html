Components

Progress

A determinate task bar: a .ds-progress row holding an optional label and value, then a .ds-progress-track with a .ds-progress-indicator whose width is set inline. Six tones recolor the fill, and an indeterminate mode animates a sliding segment.

Determinate

The fill width is set with an inline style="width: …%" on the indicator. The track is a separate element so the label and value can sit in the same row above it.

Track + indicator 
<div class="ds-progress" role="progressbar"
     aria-valuemin="0" aria-valuemax="100" aria-valuenow="35">
  <div class="ds-progress-track">
    <div class="ds-progress-indicator" style="width:35%"></div>
  </div>
</div>

With label & tone

The label and the value are siblings of the track inside .ds-progress, which wraps — so the value sits at the end of the caption row and the track takes the line below. --tone-* recolors the fill.

Label + tone-success / -warning / -danger
Uploading export 62%
Disk usage 80%
Quota 95% 
<div class="ds-progress ds-progress--tone-success" role="progressbar"
     aria-valuemin="0" aria-valuemax="100" aria-valuenow="62">
  <span class="ds-progress-label">Uploading export</span>
  <span class="ds-progress-value">62%</span>
  <div class="ds-progress-track">
    <div class="ds-progress-indicator" style="width:62%"></div>
  </div>
</div>

Indeterminate

When the total isn’t known, --indeterminate animates a segment sliding across the track (slows under reduced-motion).

.ds-progress--indeterminate 
<div class="ds-progress ds-progress--indeterminate" role="progressbar"
     aria-valuemin="0" aria-valuemax="100" aria-label="Loading">
  <div class="ds-progress-track"><div class="ds-progress-indicator"></div></div>
</div>

React

The <Progress> component renders its own track and indicator, so a caller writes only the label and the value. It is Base UI's Progress underneath: value={null} is the indeterminate state and the ARIA is the primitive's.

<Progress> 
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@diametral/design-system/react";

<Progress value={62} tone="success">
  <ProgressLabel>Uploading export</ProgressLabel>
  <ProgressValue />
</Progress>

<Progress value={3} max={5} />

{/* null is indeterminate — the segment slides. */}
<Progress value={null}>
  <ProgressLabel>Syncing</ProgressLabel>
</Progress>
